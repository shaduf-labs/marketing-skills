Research report · Run 2 · 22 September 2026

Compare five source-inspected marketing skills

Choose a skill by the output you need, the access it states, and the review that must happen before use. This report compares five records from the earlier source-inspection report. It does not add source inspection, installation, credential use, or testing.

Evidence limit: These are source descriptions, not guarantees about a host, model, cost, data handling, accuracy, or marketing outcome. No source states direct publishing, sending, deployment, ad-account operation, or spend changes for these five packages.

Start here

  1. Need a page draft?Use Copywriting for a reviewable draft when authorized context is available.
  2. Need a plan or research?Use Content Strategy for planning, Competitor Discovery for a confirmed public-web list, or Search Page Audit for one authorized public URL.
  3. Need export analysis?Use Ad Campaign Analyzer only with authorized metrics and a budget decision-maker who can review assumptions.
  4. Need an action?Choose none of these five for publishing, sending, deployment, or account operation. Those capabilities are not stated.

Comparison

“Not stated” describes the inspected skill text. It does not prove that a particular host or future version has no account, cost, network, or data requirement.

Copywriting

Draft

Choose when you need
A homepage, landing, pricing, feature, about, or product-page draft.
Stated access and input
Authorized audience, offer, proof, and page context. No account, key, integration, local executable, model, cost, or internet requirement is stated in the inspected text.
Do not choose when
You need a plan, public-web research, a URL audit, campaign analysis, or direct publication.
Review before use
Check factual claims, testimonials, brand fit, accessibility, legal requirements, and the publication target.

Content Strategy

Plan

Choose when you need
Pillars, topic clusters, buyer-stage mapping, priorities, gaps, or a first-month editorial calendar.
Stated access and input
Business and customer context; competitor/forum research uses internet. External keyword data is optional. No required account or key is stated.
Do not choose when
External research is not permitted, shared business/customer material is not authorized, or immediate writing/publishing is required.
Review before use
Approve sensitive-data handling; verify cited competitive and keyword evidence; approve the plan and each execution step.

Competitor Discovery

Research

Choose when you need
A dated, reviewable public-web competitor set with names, URLs, types, queries, and next steps.
Stated access and input
Product positioning, audience, optional known competitors, web search, and site fetching. No credential, API, or integration is stated.
Do not choose when
Web access is not allowed, current competitor facts cannot be verified by a person, or broad scraping/data retention is required.
Review before use
Confirm the list. Recheck time-sensitive claims before public comparisons or sales use.

Search Page Audit

Audit

Choose when you need
A scored 38-point audit and prioritized fixes for one supplied page.
Stated access and input
It fetches the supplied URL plus same-domain robots.txt, sitemap.xml, and llms.txt. No credential, integration, local tool, model, or cost is stated.
Do not choose when
The URL is protected or not authorized, web access is not allowed, or an automatic site change is required.
Review before use
Confirm URL authorization; validate findings, scores, crawler-policy interpretation, and proposed changes before deployment.

Ad Campaign Analyzer

Analysis

Choose when you need
CPA, ROAS, LTV:CAC framing, creative-fatigue review, and stop/hold/scale recommendations from an export.
Stated access and input
Authorized CSV, table, or pasted metrics. No ad-platform credential, API, integration, local executable, named model, or cost is stated.
Do not choose when
Campaign data cannot be shared safely, account operation is expected, or no authorized decision-maker can review a spend decision.
Review before use
Check data authorization, attribution window, margin/LTV assumptions, statistical adequacy, and learning constraints before changing budget.

Use the least-access route that fits

  1. For a first draft, start with Copywriting when authorized page context is enough.
  2. For public-web work, use Competitor Discovery or Search Page Audit only when web access and a human review step are approved.
  3. Use Content Strategy when the planning outcome justifies authorized business/customer input and public-web research.
  4. Reserve Ad Campaign Analyzer for an authorized export and a human who can approve or reject a budget decision.
  5. Stop if the task requires credentials, paid services, sensitive data, publishing, sending, deployment, or a spend change that has not been approved for review.

Evidence and review limits

  • The five packages were source-inspected on 22 September 2026 in Run 1. This report does not re-open those sources.
  • Primary repository links use main branches and may change. No immutable commit SHA, release date, or captured last-updated date is available for these records.
  • No package was installed. No credentials were used. No installer behavior, host compatibility, dependencies, cost, security, privacy, legal status, accessibility, accuracy, SEO result, or marketing outcome was tested.
  • Review the current source before use. Share only authorized, minimum data. Treat output as a draft, plan, research note, audit, or analysis until an authorized human approves a consequential action.
