Research note · Run 1

Source-inspected portable marketing skills

Original owner repositories and their SKILL.md files were examined on 22 September 2026. No installation, credential entry, API call, scrape, code execution, marketplace ranking, or outcome test was performed.

Evidence status: source-inspected, not independently tested. “Compatible” below means a maintainer states it; it is not an interoperability result. Repository ownership, license, and instructions are provenance evidence—not a security audit or performance promise. Branch links may change.

Selected first set

The same four checks appear on every record so a reader can compare a skill without using a wide table.

Copywriting

Corey Haines · MIT

Job / output
Draft or improve marketing-page copy.
Declared access
No account, key, integration, local executable, model, or cost stated in the inspected skill text. Internet not stated as required.
Human review boundary
Check facts, testimonials, brand fit, accessibility, legal requirements, and publication target.

Content Strategy

Superamped · MIT

Job / output
Content pillars, topic clusters, buyer-stage mapping, priorities, gaps, and an editorial calendar.
Declared access
Internet for competitor/forum research; external keyword data optional. No required account or key stated.
Human review boundary
Approve the plan; validate evidence and sensitive-data handling before production or publishing.

Competitor Discovery

Superamped · MIT

Job / output
Dated competitor table with names, URLs, classifications, queries, and next steps.
Declared access
Internet for search and page fetching; no credentials or integration stated.
Human review boundary
Confirm the list and fact-check time-sensitive public comparisons or sales claims.

Search Page Audit

Superamped · MIT

Job / output
38-point audit of a supplied URL with prioritized fixes.
Declared access
Internet to fetch URL, robots.txt, sitemap.xml, and llms.txt. No credentials stated.
Human review boundary

Ad Campaign Analyzer

Superamped · MIT

Job / output
Red/yellow/green assessment and stop/hold/scale recommendations from an export or pasted metrics.
Declared access
CSV, table, or pasted text; no ad-platform credentials, API, integration, or special requirement stated.
Human review boundary
Check numbers, attribution, margins, LTV, statistical adequacy, and learning constraints before a budget change.

Compatibility and freshness

The Core Haines repository states support for Claude Code, Codex, Cursor, Windsurf, and Agent Skills-compatible hosts; its selected skill metadata version is 2.0.2. The Superamped repository states support for Claude Code, Codex, Cursor, OpenCode, and compatible hosts; selected skill metadata versions are 1.0. The repositories provide install/copy guidance, but no install was performed. No release date or stable commit SHA was captured for these records, so last-updated date is unknown.

Sources: Core Haines installation guidance · Superamped installation guidance · Core Haines license · Superamped license.

Why these five, not the larger set

The initial selection favors draft, plan, research, audit, and pasted-data analysis before tools that guide production instrumentation, rely on paid credits, or add a broader service/data surface. Examples deferred for later comparison include a broader SEO audit, analytics tracking, competitor profiling, and keyword research with an external MCP/API-key and credit dependency.

Known limits and next checks

  • Re-open each source and capture an immutable commit SHA and actual latest update before a future refresh.
  • Inspect referenced files and installer behavior in a disposable, no-credential environment only if authorized.
  • Verify each intended host’s current discovery and install behavior; do not turn a command into an unconditional safety claim.
  • Keep customer and campaign data out of trials unless authorized; use least-privilege access and human approval for consequential actions.
