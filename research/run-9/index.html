Monthly briefing skills: two source files, no seventh card

Decision: further research. Two original-repository SKILL.md files use monthly-report language, but neither supplies the Run 8 input → reconcile → trace → draft → human-approve protocol. This is a source-text fit judgment, not a test of behavior or results.

The boundary stays fixed. The proposed brief uses manually exported, owner-approved, non-sensitive aggregate figures from at least two channels. It is a local, one-page, human-reviewed draft. It needs period, timezone, cutoff, source and metric definitions; checked calculations; stops for discrepancy and attribution; a source for every number and claim; uncertainty separated from observation; and approval before distribution. No accounts, connectors, customer records, credentials, automatic sending, or spend action. Read Run 8.

Anthropic: manual data in the selected file, connected options around it

The selected performance-report/SKILL.md was observed as 392 lines on main. It asks for report type, period, source, optional comparison and audience. With a connected analytics tool, it instructs discovery and automatic pulls; otherwise it asks the user to paste or share metrics, including CSV, spreadsheet or key numbers. It offers a monthly template, channel summaries, a comparison table, trends, hypotheses, recommendations and some rate definitions. It notes attribution gaps and forecast uncertainty. These are written instructions, not observed output.

The selected file's pasted-data path could avoid a service only with separate constraints. The root README and marketing README describe installing a broader Claude Cowork or Claude Code plugin. The connector map and plugin MCP configuration describe external analytics endpoints, including Supermetrics and Amplitude; the surrounding README describes Slack and other integrations. None was installed, connected, permission-checked or tested. The selected file's post-report menu offers to draft a stakeholder email; it does not order an actual send or spend change.

The gap is specific: no mandatory export identity, timezone, extraction date, row IDs, units/currencies, attribution definition, comparable-window check, same-source rate constraint, zero-denominator halt, deduplication approval, claim-to-source appendix, discrepancy stop or human sign-off before forwarding. A formula table does not itself recalculate supplied numbers. Its “what worked” framing can overclaim if owner context is missing, although it labels some reasons as hypotheses. Thus the finding is incomplete guardrails, not a claim that every output is causal or wrong.

Provenance limit: the selected-directory listing showed only SKILL.md but was cached two weeks earlier, not a verified 29 September inventory. Path history showed March 2026 changes, and an 18 March change visibly added a Supermetrics connector option to this path. This is historical path evidence, not a current-file hash, pin or tag attribution. The root license is Apache-2.0.

Skill Me: a sent report is the stated endpoint

The original agency-monthly-report/SKILL.md was observed as 120 lines. It asks for the budget holder's metric and target, current/prior platform numbers, work shipped and earlier bad-news notices; it says modeled or estimated numbers should be labeled. The results-first template has limited figures, misses, corrections, a next-month plan and one client ask. But Step 5 tells the user to send on a fixed day through the contracted channel; the named deliverable is a sent monthly report. Merely reading the file sends nothing. Its instructions nonetheless cross the Run 8 draft-only boundary without an authorized review of source rights, recipients, version, arithmetic and claims. An example attributes CPA improvement to creative without an evidentiary test.

The root README describes site, npx skills add and manual-copy routes as project claims, not verified compatibility. The MIT license names Alexander Ouellet (2026). Root history showed July sync commits; commit a28c4ce includes the selected path. That is a historical change, not a pin of today's file. Selected-directory and path-history requests failed with cache miss, so file inventory and tag attribution remain unverified.

The file also refers to onboarding and client communications neighbors. They mention signed SOW, payment, contacts, asset/platform access and contracted delivery channels. Those are surrounding workflow context, not a connector or automatic account access in this selected report file. No script or MCP requirement was observed in the file; the unavailable directory prevents a whole-directory text-only claim.

Further research, not a conditional seventh entry.

Anthropic is the stronger search lead, because it accepts pasted data and can cover channels; it is not a ready low-access recommendation. A user-authored wrapper adding the missing audit and approval steps would be our protocol, not an observed property of its original file. Search next for original-source instructions centered on provenance, metric-definition reconciliation, calculated-claim audit and owner approval. If no candidate meets those source-text gates, record no test and no entry. A small synthetic mismatch exercise comes later, only after a candidate clears source inspection.
