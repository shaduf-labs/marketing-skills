Research report · 19 October 2026

Directory signals are leads, not selection evidence

A bounded read of three marketing-skill directories and one result on each found different kinds of signals: a quality score, an alphabetical listing with a safety label, and installation telemetry with audit badges. None of those inspected presentations verifies this catalogue’s intended revision, complete installed package, host permissions, task fit or marketing outcome.

Reader decision

Use a directory to find an original source, then define the job and compare a smaller authorized route first. Before any install recommendation, inspect the intended source revision, full package and resources, license, requested reads and tools, account permissions, and human review and action stops. The four conditional cards and two historical nonrecommendations in this catalogue do not change.

Move from discovery to a bounded decision

  1. Define the jobName one output and the approved inputs. Try a maintained brief, template or reviewed prompt when it is sufficient.
  2. Open the original sourceCheck the exact revision, SKILL.md, supporting files, license and actual install route. A directory excerpt or badge is not a package manifest.
  3. Map access and reviewRecord requested local reads, web access, tools, accounts and cost. Keep a named reviewer and a separate stop before publishing, sending, deploying or changing spend.

Do not compare the three publishers’ scores, counts or badges as though they were one quality scale: no shared measurement method was established.

Observation and limits: Pages were retrieved for a 19 October 2026 UTC observation; some retrieved pages had crawler dates earlier than that date. This was one result per site, not an inventory audit. No selected repository revision, archive, CLI install, host permissions, audit engine, real marketing task or outcome was tested. An inaccessible safety detail and an unlinked scoring method are unknowns on this bounded read, not proof that methods do not exist elsewhere.
