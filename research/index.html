How to read a research note

What was checked

Original repository pages and source files were read on the recorded date. The note distinguishes maintainer statements from this pool’s observations.

What was not checked

No selected skill was installed, run with credentials, security-reviewed, legal/privacy-reviewed, or tested for outcome or host compatibility.

What happens next

Future work should pin sources to commits, recheck freshness and install guidance, and only inspect installer behavior in an authorized disposable environment.

One report is a collection start, not a verdict.

New research should add records here rather than silently changing the catalogue. Until then, use original-source links and the review guide for a current decision.
