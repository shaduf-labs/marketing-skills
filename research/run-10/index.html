Research report · Run 10 · 30 September 2026

Close the reporting-skill search for now

Two more original SKILL.md files fail the fixed offline-brief gates. This bounded search ends with six catalogue entries, no seventh card, and no synthetic test. It does not prove that a suitable skill exists nowhere.

Decision boundary: Run 8 defined a one-page local draft from owner-approved, non-sensitive, manually exported aggregates for at least two channels and two closed periods. The instructions must require export identity, metric and attribution definitions, comparable windows, recomputation and mismatch stops, source-to-number and source-to-claim trails, stated uncertainty, and an authorized owner’s approval of the exact version before release. A live account, credential, installation, automatic send or spend change is outside first use. Run 8 brief · Run 9 shortlist.

ClawFu: the script route changes first use

The selected report-generator/SKILL.md was displayed as 64 lines on main. It offers reports and names statistical calculation, but does not direct a source/export ledger, comparable metric definitions, independently checked claims, a source-to-claim map, or authorized sign-off. General caveats about prediction and expertise are not a per-claim uncertainty rule. Saying a user decides definitions is not a reconciliation protocol.

The selected file instructs dependency installation and python scripts/main.py report commands. A cached directory listing showed SKILL.md and scripts/, but the script page could not be fetched. Its behavior and today’s inventory are unknown. The README presents MCP, clone and copy routes and calls the collection Markdown context; that generic description does not erase this file’s install-and-script instructions. The root license is MIT (Guia, 2026). Direct selected-path history was unavailable, so there is no selected-file SHA/date, current pin, or tag attribution.

Digital Marketing Pro: real review steps, not the required approval

The selected analytics-insights/SKILL.md was displayed as 248 lines on main. It requests a KPI’s definition, source, benchmark, cadence and owner, the data stack and quality issues, plus monthly comparisons and channel breakdowns. Its anomaly sequence checks tracking faults and reporting delay before interpretation. The reporting templates include a cross-channel table, budget-versus-spend reconciliation, source-of-truth validation and another teammate’s review before sending. These are safeguards, but budget-versus-spend is not reconciliation of inconsistent platform definitions or attributed conversions. Source-of-truth validation is not a required recomputation with zero and mismatch stops. Teammate review is not the authorized owner approving the exact figures, claims, recipient and version.

The file also directs local brand-profile reads and a campaign-history Python script. A cached selected directory listing showed ten Markdown references besides SKILL.md; the root repository has agents, commands, scripts and connector examples. A connector was not shown mandatory for this selected file, and none was used. The reporting reference says to send on schedule, but inspection does not establish an automatic sending action. The root license is MIT (Digital Marketing Pro, 2026). Direct selected-path history was unavailable; no selected-file SHA/date, current pin or tag is claimed.

No seventh card and no test

Close this reporting search for the present decision. A generic prompt plus human spreadsheet audit remains Run 8’s bounded non-package alternative, not a tested replacement. Reopen only for a documented new source file/change that visibly supplies every gate and a low-access first use, or owner/user evidence that changes the brief. A synthetic mismatch walkthrough was deliberately not run because neither file passed source inspection.

The next unmet job

Define a human-reviewed campaign launch brief for one approved offer and two channels, using owner-provided goals, a budget ceiling, proof and constraints. It should end in a reviewable plan, not account activation or a spend change. First check audience evidence and overlap with the existing Content Strategy and Ad Campaign Analyzer entries; do not presume a new skill or demand. This is a research direction, not a catalogue recommendation.

The bounded search also scope-screened, without full audit, a live-dashboard skill, a paid-ad analytics skill, and a dashboard-design skill. Each missed the offline cross-channel brief at the job level. This was not an exhaustive search.
